## Tips for Creating Sprites

1. **Consistency**: All sprites should be the same size and have the mouth in the same position
2. **Transparency**: Use transparent backgrounds (PNG format)
3. **Style**: Match your mascot's art style
4. **Position**: Center the mouth in the image
